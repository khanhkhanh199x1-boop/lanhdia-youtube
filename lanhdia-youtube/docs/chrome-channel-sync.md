# Trung tâm điều khiển Chrome · Lãnh Địa YouTube

## Cài một lần trên Windows

- Điều kiện: Windows 10/11, Google Chrome Stable cài kiểu chuẩn, cùng một tài khoản Windows và thư mục `Google\Chrome\User Data`. Không hỗ trợ Guest, chế độ ẩn danh, Portable, Chrome do phần mềm quản lý profile khác khởi chạy hoặc điều khiển từ xa sang máy khác.
- Mở [Quản lý Kênh](https://lanhdiayoutube2027-beryl.vercel.app/channels). Tải [Windows Helper v2](https://lanhdiayoutube2027-beryl.vercel.app/downloads/lanhdia-windows-helper.zip), giải nén và chạy `cai-dat-helper.bat` **không** dùng Run as administrator. Cần .NET Framework 4.x có sẵn trên Windows. Batch chỉ biên dịch `Host.cs`/`BuildInfo.cs` tại máy và đăng ký Native Messaging trong `HKCU`. Không đổi Execution Policy, không tải lệnh mạng. Các nút thư mục/Helper cũ không dùng gói này.
- Tải [tiện ích Chrome v2](https://lanhdiayoutube2027-beryl.vercel.app/downloads/lanhdia-chrome.zip), giải nén ra thư mục cố định. Mỗi hồ sơ (gồm Chrome trung tâm và **từng hồ sơ YouTube cần dùng**) vào `chrome://extensions` → **Chế độ dành cho nhà phát triển** → **Tải tiện ích đã giải nén** → chọn cùng thư mục có `manifest.json`. Gỡ tiện ích v1 trước để không ghim nhầm. Ghim bản mới. `Alt+Shift+Y` là phím gợi ý nếu không trùng.

## Ghép hồ sơ, nhận kênh, mở lại

1. Chọn một hồ sơ Chrome làm bàn điều khiển, đăng nhập Lãnh Địa YouTube ở đó. Vào **Quản lý Kênh → Thiết lập hồ sơ trên máy này**. Mở `chrome://version`, lấy phần cuối của dòng **Profile Path**, không phải tên hiển thị: `Default`, `Profile 1`, `Profile 48`… Chọn thư mục, bấm **Mở tab xác minh**. Nếu lỡ chọn một hồ sơ khác, xác minh phải từ chối. Quay lại web, bấm **Kiểm tra kết nối** nếu cần, rồi **Chọn làm trung tâm**. Mỗi máy dùng một trung tâm đang hoạt động; đổi workspace không nhận hàng chờ workspace cũ.
2. Trong một hồ sơ có kênh đăng nhập sẵn, mở tổng quan **YouTube Studio của chính kênh**, URL `/channel/UC…`. Bấm biểu tượng tiện ích. Lần đầu xác minh thư mục hồ sơ như trên rồi bấm **Đồng bộ kênh này**. Không cần đăng nhập Lãnh Địa YouTube trong hồ sơ nguồn. Tab video, thiết lập Google và trang công khai không được dùng để ghép quyền mở Studio.
3. Sau thiết lập, bấm biểu tượng tiện ích trong Studio **một lần**. Helper gửi ID kênh và mở tab **Quản lý Kênh trong Chrome trung tâm**. Web tự thêm/cập nhật theo ID, không có form bắt buộc lưu lại. Dấu ✓ trên biểu tượng là đã gửi; kết quả thêm/cập nhật hiển thị trên web. Nếu web mất đăng nhập, đăng nhập lại ở Chrome trung tâm; yêu cầu trên máy tồn tại 30 phút. **Nhận kênh đang chờ** nhận tối đa 12 yêu cầu/lượt, hữu ích khi mạng lỗi hoặc tab vô tình đóng.
4. Trên hàng kênh vừa nhận, bấm **Mở Studio** (hoặc chọn **Trang kênh / Nội dung / Số liệu phân tích**) để mở trong hồ sơ đã xác minh. Không phải chọn tài khoản lại nếu phiên Studio còn hợp lệ. Nếu hồ sơ bị xóa/tạo lại/chuyển máy, không tự chuyển sang Chrome mặc định. Chỉ tên profile đã xác minh mới được dùng, không dùng trường nhập tay cũ. Muốn chuyển hồ sơ: bấm **Sửa → Gỡ ghép Chrome**, rồi bấm tiện ích trong Studio ở hồ sơ mới hoặc nhận lại yêu cầu đang chờ. Thao tác chỉ gỡ liên kết, không xóa kênh hay quyền đã cấp.

**Thử trước với một kênh**: xác minh, thấy web báo thêm/cập nhật, đóng cửa sổ Chrome của hồ sơ nguồn rồi bấm Mở Studio để xác nhận lại đúng ảnh đại diện/hồ sơ. Làm tiếp với các kênh khác sau khi máy đã chạy ổn.

## Dữ liệu nào tự cập nhật?

- ID UC, URL chuẩn và trạng thái ghép hồ sơ được lưu ngay cả khi không có YouTube API. API `POST /api/channels/chrome-sync` chỉ áp dụng theo phiên web chủ workspace, giữ nguyên ID tài liệu, số liệu nhập tay, Gmail, BKT, trạng thái, ghi chú, quyền nhân viên và bản nháp. Cùng một kênh không sinh bản ghi trùng; xung đột hồ sơ yêu cầu chủ động gỡ ghép. Không ghi đè tên tự đặt.
- Tên, handle và quốc gia YouTube cung cấp, subscribers có thể bị ẩn/làm tròn, tổng video công khai và lượt xem hiển thị từ **YouTube Data API v3**. Google Cloud Console → bật API → tạo API key giới hạn cho YouTube Data API v3. Vercel → Settings → Environment Variables → Production → `YOUTUBE_DATA_API_KEY` → triển khai lại. Không dùng khóa Firebase, tiền tố `VITE_` hoặc chia sẻ khóa trong chat. Khi API lỗi vẫn có thể ghép và lưu ID. Số liệu lấy ngay lúc đồng bộ; kênh bật tự làm mới cập nhật trên trang đang hiển thị mỗi 15 phút. Không có lịch tải số liệu chạy khi web đóng. Số liệu API là bản hiển thị tạm; không lưu snapshot vào bảng để thay dữ liệu người dùng nhập.
- Gmail quản lý, giờ xem 12 tháng, gậy bản quyền/cộng đồng, trạng thái bật kiếm tiền, danh mục nội bộ và ghi chú **không** lấy từ phiên Studio. YouTube Analytics có thể cung cấp thời lượng xem khi chủ kênh cấp OAuth đọc riêng; giờ xem Analytics cũng không đồng nghĩa giờ xem công khai hợp lệ để bật kiếm tiền. Không báo những trường chưa có dữ liệu là 0. Bản này không upload/đăng video, sửa YouTube hoặc truy cập AdSense.

## Kiến trúc và an toàn

- Manifest V3 có `activeTab`, `storage`, `nativeMessaging`. Không có quyền đọc cookie, token Google, lịch sử, Gmail, nội dung Studio, truy cập địa chỉ localhost hoặc host permission trên YouTube. ID ổn định từ khóa công khai trong manifest. Bridge từ trang cấp phép đúng origin sản xuất và ba đường dẫn (`/channels`, `/videos`, `/chrome-verify`), chỉ khung chính. Windows Host chỉ cho đúng extension ID; không mở cổng mạng, không có lệnh từ xa/polling và không đọc file cấu hình Chrome.
- Hồ sơ xác minh bằng một lượt mở lại Chrome với `--profile-directory`, nonce 120 giây và ID cài đặt riêng trong từng hồ sơ; một dấu ghép không bí mật trong thư mục hồ sơ ngăn chọn nhầm khi tái sử dụng đường dẫn. Cấu hình/hàng chờ nằm trong `%LOCALAPPDATA%\LanhDiaYouTube\ChromeHub`. Helper gắn quyền mở cục bộ theo workspace, UC và khóa hồ sơ sau API lưu thành công. Không truyền đường dẫn đầy đủ, thông tin đăng nhập hay tiêu đề Studio trong handoff. URL fragment chỉ có mã một lần, không đủ để tạo bản ghi nếu thiếu yêu cầu cục bộ đúng trang trung tâm và quyền web.
- Nút Mở dựng bốn URL YouTube/Studio cố định từ UC hợp lệ; không shell, đường dẫn file, chuỗi lệnh hay URL tùy ý. Không tự fallback hồ sơ chưa xác minh. Web không mở máy nào không có Helper và tiện ích trên máy. Gỡ Helper bằng `go-helper.bat`; các bản ghi, thư mục Chrome, phim và phiên Google không bị xóa.
- Nhân sự vẫn giới hạn Kênh/Video/SEO theo phân công, không nhận cấu hình hồ sơ hoặc API ghép/tháo ghép. Luồng nhập v1 dạng review, CRUD tay, đồng bộ Sheet không xóa kênh không có trong Sheet và tiện ích iframe YouTube giữ nguyên.

## Build và kiểm thử

- `npm run build` tạo `dist/downloads/lanhdia-chrome.zip` cùng `dist/downloads/lanhdia-windows-helper.zip`; `node scripts/pack-vercel-output.mjs` gói frontend/API lên cùng dự án Vercel. `tests/chrome-helper.test.mjs` kiểm tra đúng mã C# trong gói, protocol và argv bằng Mono; `tests/channel-management.test.ts` kiểm tra API với Firestore Emulator.
- Chromium chạy tiện ích thật và C# qua Native Messaging trên Linux giả lập hai hồ sơ `Default`/`Profile 48`: hồ sơ sai bị từ chối, bấm toolbar tự thêm/cập nhật cùng tài liệu mà không mở form, Chrome nguồn không cần đăng nhập web, Helper mở lại Studio ở profile đã đóng. Fragment bịa bị từ chối. Auth, YouTube API và Studio trong fixture; chưa chạy bộ cài Registry hoặc phiên Google thật trên máy Windows của khách. Bài thử thật hướng dẫn ở trên.
- Tài liệu: [Chrome Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging), [Chrome externally_connectable](https://developer.chrome.com/docs/extensions/reference/manifest/externally-connectable), [YouTube channels.list](https://developers.google.com/youtube/data/reference/rest/v3/channels/list), [YouTube Analytics metrics](https://developers.google.com/youtube/analytics/metrics), [YouTube API Developer Policies](https://developers.google.com/youtube/terms/developer-policies).
